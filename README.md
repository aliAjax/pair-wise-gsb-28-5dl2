# 配送任务拖拽排班（含逆向回仓闭环）

- 行业：物流
- 技术栈：React、Vite、TypeScript、Ant Design、dnd-kit
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 正向排班

- 订单：`待分配 → 已分配 → 已签收 / 拒收 → 已回仓`
- 确认排班与回仓接单都会校验司机时段占用，看板实时展示每位司机各时段的任务。

## 逆向回仓闭环

- 拒收（含签收后退货）自动生成回仓单，记录原订单、取件时段、司机、车辆与原因。
- 规则 R1：同一订单同时只能有一张有效回仓单。
- 规则 R2：司机在取件时段已有任务（配送或已接单回仓）时不能接单/排班。
- 规则 R3：回仓重量与原单不一致须先复核，复核通过才能完成回仓。
- 回仓完成自动释放司机时段，并生成带原因的修订；原签收单为原始凭证、不可改写，所有变更体现在修订链。
- 触发规则的冲突会记录订单、司机、时段与触发规则，详见「冲突记录」页签。
- 订单、回仓单、签收单、修订链与冲突记录均持久化在 localStorage，刷新后排班、回仓状态与修订链保持一致。
